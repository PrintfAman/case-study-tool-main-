## Status rules

- **Verified**: implementation passed an applicable automated or live check.

- **Blocked (runtime)**: safe implementation exists, but external credentials or service access prevent live verification.

Do not mark an item Verified based on file presence or an earlier session's claims.

## Repository and workflow audit

- **Frontend:** React 19, TypeScript and Vite under `frontend/`. `main.tsx` mounts one `App.tsx`; auth and project API services call the backend with credentials. `App.new.tsx` is an unreferenced duplicate and is not part of the build.
- **Backend:** Express 5 and TypeScript under `backend/`, layered as app/routes/controllers/services/middleware. API responses use `{ success, message, data, error }`.
- **Database:** local SQLite, created by `backend/src/storage/database.ts`; generated database files under `backend/storage/` are ignored while the source module remains tracked. `case_studies` supports version history.
- **Authentication:** persistent SQLite sessions; HMAC-signed HttpOnly cookie; the browser automatically restores or creates a private guest workspace; project, analysis, history and report endpoints remain user-scoped; origin check for browser mutations. Login and registration screens are removed.
- **Website flow:** input validation → DNS/IP policy → robots check → bounded same-host crawl → metadata/text evidence → case study synthesis.
- **GitHub flow:** URL validation → GitHub REST metadata/language/tree → bounded manifest/source inspection → evidence object.
- **Synthesis flow:** website/GitHub/Tavily evidence (when available) → optional Groq response validated and merged with a deterministic source-specific fallback → versioned database row.
- **Report flow:** latest or chosen case-study version → `pdf-lib` cover/contents/sections/tables/footers → report file keyed to project id → authenticated download.
- **External configuration:** Groq is configured locally and report synthesis was runtime-verified; Tavily remains unconfigured. Groq-generated field suggestions were not observed in the sample response. GitHub public API and a public crawler target were verified outside the network sandbox.
- **Build tooling:** backend has typecheck/build/test/live-smoke scripts. Frontend has typecheck/build; no lint script or frontend test runner is configured.
